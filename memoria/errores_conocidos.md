# Errores conocidos — DoonFlow

Registro de errores/bugs/limitaciones conocidas que no se van a resolver de inmediato, para no perder tiempo redescubriéndolas. No es un changelog de fixes — cuando se resuelve un error, se mueve a "Resueltos" con la fecha y el commit/PR que lo corrigió, no se borra.

Formato de entrada:

```
## [fecha] Título corto
- Módulo: nombre del módulo o "transversal"
- Síntoma: qué se observa
- Causa (si se conoce): por qué pasa
- Workaround: cómo evitarlo mientras no se resuelve
- Agente responsable: quién lo va a resolver
```
